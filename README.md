# Sunburst 本地照片工作台

基于 OpenAI 的 [openai-imagegen-demo](https://github.com/openai/openai-imagegen-demo) 改造。在 Mac mini 本机运行，无应用账号、无登录、无额外远程服务器。AI 生成需要联网调用 OpenAI，使用你自己的 API key 和额度。

## 快速启动（这台 Mac）

你已经安装过依赖、配置过密钥，平时在终端执行：

```bash
cd /Users/photo-king/GPT_Image_Gen
npm run dev
```

然后用浏览器打开 **http://127.0.0.1:3000**。运行期间保持这个终端窗口打开。

- **停止**：在运行服务的终端按 `Control + C`。
- **重启**：先按 `Control + C`，再执行 `npm run dev`。
- **更换密钥**：编辑项目根目录 `.env.local`，保存后重启服务并刷新页面。
- **端口已占用**：先停止旧的工作台进程，再启动；不要反复打开多个服务。

## 第一次安装 / 在另一台 Mac 使用

需要 Node.js 20.9 或更高版本和 npm。项目已在 Node.js 20.11 上验证。

### 1. 下载项目并安装依赖

```bash
git clone https://github.com/Photo-king/GPT_Image_Gen.git
cd GPT_Image_Gen
npm ci
```

### 2. 配置自己的 API 密钥

仅在 `.env.local` 不存在时复制模板，避免覆盖已经保存的密钥：

```bash
test -f .env.local || cp .env.example .env.local
open -e .env.local
```

在打开的文件中填写并保存：

```dotenv
OPENAI_API_KEY=你的真实API密钥
```

密钥从 [OpenAI API 密钥页面](https://platform.openai.com/api-keys) 创建。使用自己的 OpenAI API 项目额度；不需要注册或登录本工作台。模型可用性取决于该项目的权限。

`.env.local` 已排除在 Git 之外。不要把真实密钥写入 README、截图、聊天或 `NEXT_PUBLIC_*` 环境变量。前端只读取“已配置 / 未配置”状态，不接收密钥本身。

### 3. 启动并打开页面

```bash
npm run dev
```

访问 **http://127.0.0.1:3000**。页面显示“API Key 已配置”表示本机服务读到了密钥，不代表 OpenAI 已验证密钥有效性。

### 可选：生产模式

先停止开发服务，再执行：

```bash
npm run build
npm start
```

生产模式下，修改代码后需要重新执行 `npm run build`。只修改密钥时重启服务即可。

两种启动模式都只监听本机 `127.0.0.1`。使用同一个浏览器、地址和端口，才能看到同一份浏览器版本记录。

## 照片精修：从导入到下载

第一次可以按这个顺序操作：

1. 选择“照片精修”，点击“导入已调色照片”。
2. 如果想直接优化整张照片，选“整图精修”；如果只改天空、雪山或前景，选“画笔选区”并先涂抹区域。
3. 输入修改要求，例如：“保留现有色调和曝光，仅增强选区内雪山的自然纹理，不改变山体形状，不要过度锐化。”
4. 保持默认 `MAX` 画质，检查输出分辨率。局部编辑建议保持“仅合成选区，保护原图像素”开启。
5. 点击“预览费用并生成”，核对设置；勾选授权后，再点击“确认付费并生成 1 张”。
6. 等待结果。不要重复点击或关闭运行服务的终端；断线后优先用“检查已有结果”。
7. 拖动 Before/After 滑块检查变化，在 100% 下检查边缘与细节，然后下载 PNG。

### 功能说明


1. **照片精修**：导入已经调色完成的 JPEG / PNG / WebP（最大 100 MB、最多 6000 万像素，支持常见 20–50 MB 照片），写自然语言 Prompt。
2. **整图精修**：允许模型处理整张图；保留调色的要求是 Prompt 指令，不能保证所有像素不变。
3. **画笔选区**：涂抹金色区域，支持橡皮、撤销和清空。天空、雪山、前景按钮只是 Prompt 模板，不是自动语义分割。画笔直径以原图像素计算。
4. **仅合成选区**（默认开启）：API 返回后，将生成结果映射回原图尺寸，仅混合蒙版覆盖的像素。未覆盖的 RGBA 字节直接复制原图。抗锯齿边缘会混合。可分别下载 AI 原始结果和保护合成 PNG。
5. **文字生图**：不需要上传照片，直接描述目标画面。
6. **费用确认**：查看模型、画质、分辨率和官方单价，勾选后明确授权一次付费请求。
7. **比较与版本**：Before/After 滑块，100% 放大、适应窗口、拖拽平移、⌘+滚轮缩放。选择两个同来源、同尺寸版本比较；点击“以此版本继续精修”进行迭代。

## 最高画质和分辨率

固定模型 `gpt-image-2.5-sunburst`，默认 `quality=max`，单次 `n=1`，无损 PNG。

依据 [官方生成 API](https://developers.openai.com/api/reference/resources/images/methods/generate) 与 [图像指南](https://developers.openai.com/api/docs/guides/image-generation)，2026-10-18 核实：

- `quality`: `low / medium / high / xhigh / max`。
- 默认 `3840x2160`；支持竖向 `2160x3840`、正方形 `2880x2880` 和自定义尺寸。
- 宽高均为 16 的倍数，单边不超过 3840，宽高比 1:3–3:1，总像素 655,360–8,294,400。
- 超过 2560×1440 的像素量属于实验性高分辨率，账号侧仍可能拒绝请求。
- 导入照片后，自动选择接近原图比例的最大合法尺寸。API 输入与蒙版转换成同尺寸 PNG；本地原图保持原始尺寸。输出比例因 16 像素对齐可能略有差异。
- 编辑请求在浏览器→本机服务端→OpenAI 两段均用 multipart 二进制文件传输，不再受 JSON data URL 的 20 MiB 字符限制。实际发送的 PNG 与蒙版各须小于 50 MB。API 副本保持所选输出尺寸和 PNG 无损编码，不因 Base64 体积而降低画质。
- 导入保留源文件内容，不再把整张 JPEG / WebP 原图提前转换成巨大 PNG。原图的 100 MB 本地导入上限与 API 副本的小于 50 MB 限制不同；原图不会整份按原始尺寸直接发送给 API。

## 费用与防重复请求

[Sunburst 官方价格](https://developers.openai.com/api/docs/models/gpt-image-2.5-sunburst)（Standard，2026-10-18）：文字输入 $5 / 百万 tokens，图片输入 $8 / 百万 tokens，图片输出 $30 / 百万 tokens。

**不能提前给出准确总价或硬性单次费用上限**：官方指出旧 GPT Image 2 计算器无法估算 Sunburst token 消耗。因此确认窗展示按量费率与示例，不把示例当作报价。返回完整 usage 时显示按标准费率计算的参考费用，未包含潜在缓存优惠；实际以 OpenAI 账单为准。需在 OpenAI 项目中设置预算提醒，并自行核对用量。

- 点击“预览费用”不调用 OpenAI，只创建十分钟有效、本机保存的确认单，并绑定完整请求参数。
- 确认后才发送一次付费 POST。原生 fetch 不自动重试，也不自动切换模型或降画质。
- 服务端使用原子创建目录作为持久化锁：同一确认单并发、重放或重启后不会再次发起上游调用。
- 结果和状态保存在 `.local/studio/jobs/`。网页断线后点击“检查已有结果”只读取本机结果，不重新付费。刷新页面不会自动生成。
- 网络超时或进程终止可能已计费却没有结果；应用不会猜测并自动重试。先核对官方用量，再决定解除等待并重新确认新的请求。
- 旧 `/api/photobooth` 批量付费入口返回 410，旧 `/results` 页面跳回工作台。

## 原始像素与照片工作流边界

这不是 RAW / 16-bit / ICC 色彩管理软件。请从 Lightroom / Capture One / Photoshop 导出 **sRGB 副本** 后使用。

导入保留原始文件；用于 API 和本地合成时，浏览器解码为 8-bit RGBA，并将处理结果输出为 PNG。本地保护保证的是这个解码版本的选区外像素，不保证源文件二进制、RAW 信息、原始 ICC、EXIF 或高位深数据不变。蒙版给模型提供编辑指引，模型可能改变选区外内容；只有开启本地保护合成才能阻止这些变化进入最终选区外像素。

超出 API 输出尺寸的原图仍可按原尺寸合成，但 AI 区域可能被放大，不会凭空获得原图级别的真实细节。请在 100% 下检查边缘、结构偏移和纹理衔接。

## 本地保存

- 当前原图、笔画、Prompt、设置、版本和未完成请求上下文：浏览器 IndexedDB。
- 服务端确认单、请求状态和 AI 输出：`.local/studio/`，已加入 `.gitignore`。
- 原图导入时不发送到外部，点击确认生成时才发送 API 输入图片、蒙版与 Prompt 到 OpenAI。
- 浏览器配额有限，存储失败会提示；建议及时下载重要版本。清理浏览器数据会清除工作区。
- 页面读取结果及请求去重机制只适合单机使用，不应直接部署成公开服务。

## 常见问题

| 现象 | 处理方法 |
| --- | --- |
| 页面打不开 | 在项目目录执行 `npm run dev`，保持终端运行，访问 `http://127.0.0.1:3000`。 |
| 填入密钥后仍显示等待 | 页面每 5 秒检查一次配置；仍未识别时，确认编辑的是项目根目录 `.env.local`，然后重启服务。 |
| `401` / `Your API key has expired` | 在 OpenAI 后台创建新密钥，替换 `.env.local` 中的值，保存并重启。明确的认证拒绝未开始图片生成；当前通用错误提示中的“可能已计费”不适用于该情况。 |
| 画笔模式提示先选择区域 | 在照片上涂抹金色选区；无需局部编辑时切换“整图精修”。 |
| 仍看到旧的“20 MiB 编码限制” | 刷新页面并重启更新后的项目。本版已经改用二进制上传。 |
| 提示模型不可用、权限或额度不足 | 根据 OpenAI 返回的错误，检查该 API 项目的模型权限和账单额度。 |
| 存在未完成任务、无法再次生成 | 先点“检查已有结果”。只有确定需要重新请求时才“解除等待”，下一次仍需重新确认。 |
| 超时或网络断开 | 应用不会自动重试。先检查本地结果及 OpenAI 用量，再决定是否新建请求。 |
| 浏览器保存失败 | 及时下载结果；照片与版本较多时可能触及浏览器存储配额。 |
